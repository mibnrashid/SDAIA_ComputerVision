The labs

Seven Colab labs, each in an unsolved version (one-line TODOs with checks) and a solved version. Labs 1A, 1B, 2A and 2B are done in class and finished at night; 2C is optional; 3A and 3B are your portfolio pieces after the course.

How to start a lab: click Open unsolved in Colab, then Runtime → Change runtime type → T4 GPU, then run the cells top to bottom. Every TODO is one line and is checked by the cell below it (✅ or a hint). Stuck for five minutes? Open the solved version and compare. Colab forgets files between sessions, so re-run from the top when you come back.
