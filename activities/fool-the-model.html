The five failure types

  • Out-of-distribution — the input is unlike the training data (new object, camera, season, weather).
  • Typographic attack — written text in the image hijacks the prediction.
  • Counting / spatial — the model ignores how many, or where things are relative to each other.
  • Bias / shortcut — the model learned a spurious cue or reflects unbalanced data.
  • Hallucination — a vision-language model states things that are not in the image.
