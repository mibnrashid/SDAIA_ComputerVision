Glossary

Every term defined on a slide in the three decks, extracted automatically from the definition slides. 39 terms

Anchor
a pre-defined template box placed at every feature-map position. The RPN predicts, for each anchor, "is there an object?" and how to nudge the anchor to fit it.
Day 2 · slide 2.38
Attention
each part of the input looks at every other part, decides how relevant each one is, and builds its new meaning as a weighted mix of the relevant parts.
Day 3 · slide 3.16
BatchNorm
rescale each layer's outputs to a steady range (mean 0, spread 1) using the current batch, then let the network adjust with two learned numbers. Training becomes faster and more stable.
Day 1 · slide 1.97
Bounding box
the smallest axis-aligned rectangle that contains an object, described by four numbers.
Day 2 · slide 2.16
CLIP (Contrastive Language–Image Pre-training)
two encoders, one for images and one for text, trained so that an image and its caption produce similar embeddings. Trained on about 400 million image–text pairs.
Day 3 · slide 3.43
Closed-set assumption
a classifier assumes every input belongs to one of its training classes. It has no way to say "none of these".
Day 3 · slide 3.09
[CLS] token
an extra learned token added to the sequence. Through attention it gathers information from all patches, and its final value is used for classification.
Day 3 · slide 3.24
Computer vision
teaching computers to extract meaning from images and video: what is there, where it is, and what is happening.
Day 1 · slide 1.12
Convolution
slide a small grid of weights (the kernel) over the image; at each position multiply the overlapping numbers and add them up. That sum is one output pixel.
Day 1 · slide 1.40
Convolution layer
a set of kernels whose numbers are learned during training. Each kernel produces one feature map showing where its pattern appears.
Day 1 · slide 1.68
Dilated convolution
spread the kernel's taps apart so a 3 × 3 kernel covers a 5 × 5 area with no extra weights.
Day 1 · slide 1.74
Dropout
during training, randomly set a fraction of neurons (e.g. 50%) to zero each step. The network cannot rely on any single neuron.
Day 1 · slide 1.96
Embedding
a list of numbers (a vector) that represents an image's meaning. Similar images get vectors that are close together.
Day 3 · slide 3.35
Histogram
a bar chart of how many pixels have each value (0–255).
Day 1 · slide 1.36
IoU (Intersection over Union)
the area where two boxes overlap divided by the area they cover together. 0 = no overlap
Day 2 · slide 2.20
Keypoint detection
predicting the location of specific points on an object, such as 17 body joints for a person. Joined together they give a pose.
Day 2 · slide 2.12
Latent space
the compressed space of codes inside a generative model. Nearby codes produce similar images; moving through it changes the image smoothly.
Day 3 · slide 3.83
Loss
one number that says how wrong the model is on an example. Training means making this number small.
Day 1 · slide 1.57
mAP (mean Average Precision)
compute AP separately for each class, then take the mean. One number for the whole detector.
Day 2 · slide 2.77
Motion model
a guess of where each tracked object will be in the next frame, based on its recent speed and direction. The Kalman filter is the classic way to do this.
Day 2 · slide 2.104
NMS
keep the highest-confidence box, delete every other box that overlaps it by more than an IoU threshold, then repeat with the next highest remaining box.
Day 2 · slide 2.47
ONNX
a standard file format for trained models, so a model trained in PyTorch can run in other runtimes (on servers, phones, browsers) without PyTorch.
Day 3 · slide 3.94
Open-vocabulary detection
a detector that takes text prompts and returns boxes for whatever the text describes, including classes it never saw in box-labelled training data.
Day 3 · slide 3.56
Out-of-distribution (OOD)
an input unlike anything in the training data: a new object, a new camera, night instead of day. Models often fail on these silently and confidently.
Day 3 · slide 3.11
Overfitting
the model memorises the training examples, including their noise, instead of learning patterns that work on new images.
Day 1 · slide 1.92
Pixel
the smallest unit of an image: one position holding one number (gray) or three numbers (color).
Day 1 · slide 1.19
Receptive field
the region of the original image that one neuron can "see". It grows with every layer.
Day 1 · slide 1.84
Region proposal
a candidate box that might contain an object, found by a fast method that groups similar pixels (e.g. selective search). About 2,000 per image instead of 100,000+.
Day 2 · slide 2.31
ReLU
ReLU(x) = max(0, x) · negatives become 0, positives pass through · simple, fast, and trains well in deep networks
Day 1 · slide 1.79
RoI pooling
take a region of the feature map of any size and pool it into a fixed grid (e.g. 7 × 7), so every proposal gives the same-sized input to the head.
Day 2 · slide 2.35
SAM (Segment Anything Model)
a model that returns a precise mask for whatever you point at: a click, a box, or (in newer versions) a text phrase.
Day 3 · slide 3.59
Self-supervised learning
training on a task created automatically from the data itself, so no human labels are needed. The real goal is the features the model learns along the way.
Day 3 · slide 3.30
Semantic segmentation
assigning a class label to every pixel in the image. The output is a label map the same size as the input.
Day 2 · slide 2.85
Stride
how many pixels the kernel jumps each step. Stride 1 visits every position; stride 2 skips every other one and halves the output size.
Day 1 · slide 1.73
Thresholding
turning a grayscale image into black and white: every pixel above T becomes 255, every pixel below becomes 0.
Day 1 · slide 1.38
Transfer learning
reuse a network trained on a huge dataset (like ImageNet) as a starting point for your own task, instead of starting from random weights.
Day 1 · slide 1.118
Vision-language model (VLM)
a model that takes an image and text as input and produces text: descriptions, answers, extracted fields, or coordinates.
Day 3 · slide 3.71
YOLO
a one-stage detector: one forward pass of one network predicts all boxes and classes at once, with no separate proposal step.
Day 2 · slide 2.55
Zero-shot classification
classifying images into classes the model was never explicitly trained on, by describing the classes in words.
Day 3 · slide 3.46
